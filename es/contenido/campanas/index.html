CAMPAÑAS

Conceptos de campaña

SEIS MARCAS. SEIS FEEDS.

Campañas conceptuales que planeé y diseñé para negocios inventados, para que veas cómo armaría el feed del tuyo. Cada una empieza con una meta, no con una plantilla.

Todas las marcas en esta página son ficticias. Son conceptos, no trabajo para clientes.

Agenda una llamada gratis (abre en una pestaña nueva)

El método

CÓMO ARMO UNA CAMPAÑA.

01

Meta

Una meta de negocio por campaña: clientes frecuentes, registros, ventas o llamadas agendadas. Cada publicación tiene que servirle.

02

Pilares

Tres pilares de contenido, para que el feed tenga variedad sin salirse del tema.

03

Estilo

Un sistema visual de dos tipografías, una paleta corta y diseños que se repiten, para que cada publicación se reconozca como la marca.

04

Medición

Un número que vigilar por meta (guardados, clics, mensajes o registros), revisado cada mes.
